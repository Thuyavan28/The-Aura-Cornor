# The Aura Corner — Boutique Café & Lounge

> **"Where coffee meets calm, and hearts find a home"**

A boutique café & lounge web experience built with React, Vite, Tailwind CSS v4, Framer Motion, and Three.js / Lucide icons.

## ✨ Features
- **Cinematic Entrance Preloader**: Blue-themed ambient glow with logo badge animation and live progress.
- **Hero Dashboard**: Signature animated blue coffee cup illustration, ambient lighting, mouse parallax, and glowing brand typography.
- **Infinite Moving Tickers**:
  - Highlights marquee (Left to Right): *Ready in Minutes ✦ Safe Packaging ✦ Fast Delivery ✦ Great Taste ✦ Artisanal Coffee...*
  - Reviews marquee (Right to Left): Continuous smooth scroll with hover-pause.
- **Curated Gourmet Menu**: Clean, single-screen 2-column menu with diet indicators (🟢/🔴), category filters (`[ALL]`, `[STARTERS]`, `[MOMOS]`, `[MAGGIE]`, `[BURGERS]`, `[COMBOS]`, `[PASTA]`, `[DRINKS]`, `[DESSERT]`), and instant search.
- **Let's Connect Section**: Contact information, location details in Medavakkam Chennai, and direct WhatsApp chat integration.
- **Direct Table Reservation**: Modal with instant WhatsApp dispatch to the owner's phone number.
- **Full Mobile & Desktop Responsiveness**: Seamless experience across smartphones, tablets, and wide monitors.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Thuyavan28/The-Aura-Cornor.git

# Navigate into the project folder
cd The-Aura-Cornor

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Build for Production
```bash
npm run build
```
